# 04 — Add and maintain Google Drive blogs

## Add a future blog

Inside the new CMS Blogs folder, create:

```text
11_New_Blog_Name/
└── New Blog Google Doc
```

The hourly automation creates:

```text
11_New_Blog_Name/
├── New Blog Google Doc
└── portfolio.meta.json
```

For immediate publication, run:

```javascript
syncFutureBlogMetadata()
```

Then open:

```text
YOUR_EXEC_URL?action=blogs&refresh=1
```

No GitHub rebuild is required.

## Recommended metadata lines

Place these near the top of the Google Doc:

```text
Portfolio Title: Public article title
Portfolio Description: One concise summary for the portfolio card.
Portfolio Domain: AI & Cybersecurity
Portfolio Tags: Python, SOC, Retrieval, MITRE ATT&CK
Portfolio Status: In progress
Portfolio Featured: false
```

The metadata scanner uses these exact values. Missing values are inferred from the document.

## Manual metadata lock

Automatically created files contain:

```json
"autoGenerated": true
```

After manually editing a metadata file, set:

```json
"autoGenerated": false
```

The hourly scanner will preserve it.

## Supported article formatting

The custom reader supports:

- Title
- Heading 1, 2 and 3
- Paragraphs
- Hyperlinks written as URLs
- Lists
- Horizontal rules
- Tables

Keep images in the Media folder and add links to them when needed. The initial reader intentionally prioritises clean text, structure and performance.
