# 07 — Design originality and reference boundary

The MoncyDev portfolio was studied only for broad interaction principles:

- Full-screen introduction
- Cinematic pacing
- Pointer-responsive hero
- Scroll storytelling
- Horizontal work presentation
- Large expressive typography
- Interactive technology presentation

This project deliberately does not reproduce:

- The reference avatar or any 3D model
- Original illustrations, textures or source assets
- The same hero composition
- The same project-card composition
- The same colour palette
- The same custom cursor geometry
- The same typography arrangement
- The same animation timing
- Trial-only GSAP plugins
- Source components from the reference repository

The original identity here is a **Security Intelligence Journey** using:

- Canvas-generated intelligence nodes
- Security-signal motion
- Observe → Retrieve → Reason → Map → Respond storytelling
- Career-system logs
- Evidence-first project narratives
- A Drive-powered learning journal

The website is intentionally more recruiter-readable and evidence-oriented than a purely experimental art portfolio.
