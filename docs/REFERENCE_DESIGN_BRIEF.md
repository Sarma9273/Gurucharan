## What makes the reference portfolio impressive

The repository is built with React, TypeScript and Vite, with GSAP for scroll animation and Three.js/WebGL for 3D experiences. It also uses React Three Fiber, Drei, Rapier physics and post-processing libraries. ([GitHub][1])

Its strongest ideas are:

* A full-screen cinematic introduction
* A 3D character in the hero section
* Mouse and touch interaction with the character
* Custom cursor and fixed navigation
* Smooth scroll-based storytelling
* Horizontally moving project showcases
* Large typography used as a visual element
* An interactive physics-based technology section
* Sections that appear like scenes rather than ordinary website cards

The source confirms that the character tracks pointer movement, uses animation, lighting and a continuous Three.js rendering scene. The project section is pinned while the projects move horizontally according to scroll position. ([GitHub][2])

## Important limitation

We should **not clone this portfolio or modify only its text and colours**.

The repository’s licence permits studying the source and using small portions for learning, but prohibits copying the complete design, experience, original visual assets or 3D avatar. It also requires attribution when any part is reused. ([GitHub][3])

The repository owner also states that the original 3D avatar is not included and that the published project uses trial GSAP plugins that should not be used for production hosting. ([GitHub][4])

Therefore, we will borrow only the **design principles**:

```text
Immersive hero
Scroll storytelling
Large typography
Interactive projects
Selective 3D
Smooth transitions
```

Everything else will be designed specifically for you.

# Recommended architecture

We do not need to discard the current Astro system.

A strong implementation would be:

```text
Astro
├── Static pages and SEO
├── Existing project/blog content
├── Google Drive blog integration
├── Apps Script contact backend
└── React interactive islands
    ├── Three.js hero
    ├── GSAP project sequence
    ├── Interactive architecture
    └── Technology explorer
```

This gives us:

* Your current working deployment
* Existing Drive blog automation
* Existing contact backend
* Better page loading than making the entire site a 3D React application
* Selective use of 3D where it creates value
* Easier maintenance

GSAP can work with different frameworks, and its core animation features and plugins can be loaded individually rather than adding every effect. ([GSAP][8])
