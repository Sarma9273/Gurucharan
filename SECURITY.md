# Security Policy

## Supported version

The current `main` branch is the supported source baseline.

## Reporting a vulnerability

Do not disclose exploitable details in a public issue.

Use GitHub's private vulnerability reporting / Security Advisories for this repository when available. If private reporting is unavailable, contact the repository owner through the public GitHub profile and provide only the minimum information needed to establish a private disclosure channel.

Include:

- affected component or file;
- reproducible steps or a minimal proof of concept;
- security impact;
- suggested remediation, if known.

## Scope

Security reports are especially relevant to:

- the React/Vite frontend;
- the Google Apps Script backend;
- GitHub Actions and deployment workflows;
- dependency and supply-chain issues;
- cross-site scripting, injection, authentication/authorization, secret exposure and data-access issues.

Never include passwords, API tokens, private keys or other live credentials in a report.
